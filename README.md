# BIOLG VII Practice

Interactive review for BIOLG VII (Anatomy and Physiology II), Units 1 to 13: Quick Check questions, Explain It written prompts with model answers, and vocabulary flashcards. All content is based on OpenStax *Anatomy and Physiology 2e*.

| Unit | Topic | Textbook Sections |
|---|---|---|
| 1 | Endocrine System | 17.1 to 17.3, 17.9 |
| 2 | Endocrine Regulation | 17.4 to 17.6, 17.9, 17.10 |
| 3 | Blood | 18.1 to 18.6 |
| 4 | Cardiac Anatomy & Physiology | 19.1 to 19.4 |
| 5 | Blood Vessels & Hemodynamics | 20.1 to 20.5 |
| 6 | Lymphatic System & Innate Immunity | 21.1, 21.2 |
| 7 | Adaptive Immunity | 21.3 to 21.7 |
| 8 | Respiratory Anatomy & Ventilation | 22.1 to 22.3 |
| 9 | Gas Exchange & Acid-Base | 22.3 to 22.6 |
| 10 | Digestion & Metabolism | 23.4 to 23.7, 24.2 |
| 11 | Urinary System | 25.4 to 25.6, 25.8, 26.3 to 26.5 |
| 12 | Reproductive Anatomy & Hormonal Cycles | 27.1, 27.2 |
| 13 | Development & Inheritance | 27.3, 28.1, 28.2, 28.4, 28.6, 28.7 |

Flashcards for Units 9 to 13 use each unit's vocabulary resource. Flashcards for Units 1 to 8 use the OpenStax chapter glossaries.

This is a single static page (`index.html`) served with GitHub Pages at https://rizecomputerscience.github.io/Anatomy-II-StudyGuide/. To update it, replace `index.html` and commit. When you upload `BIOLG_VII_Practice_Site.html`, rename it to `index.html` so GitHub Pages serves it.
